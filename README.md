## PWA и сохранения

После полной первой загрузки игра доступна офлайн в том же браузере. Её можно установить через меню браузера. Сектора, звёзды, технологии и незавершённые бои хранятся локально; автоматической синхронизации между устройствами нет.

Для переноса прогресса из прежнего HTML экспортируйте профиль через меню старой игры, затем импортируйте его в меню веб-версии. Экспорт профиля переносит сектора, звёзды и технологии; активный бой в этот файл не входит.

По одному адресу доступны основная и тестовая сборки. Семь быстрых нажатий на номер версии на заставке переключают сборку с перезагрузкой страницы, сохраняя адрес. Тестовая помечена «ТЕСТ» и включает лабораторию с отдельными очками технологий и открытым доступом к секторам. Кнопка «Вернуться в основную» возвращает стабильную игру.

Основные сохранения используют прежние ключи, тестовые — отдельное пространство `kontur_preview_v1:`. В меню теста есть явное копирование основного профиля: переносятся сектора, звёзды и технологии, тестовые бои сбрасываются. Обратного автоматического переноса нет. Выбор сборки запоминается; одновременно открытые вкладки могут использовать разные сборки.

Обновления и кэши разделены по сборкам. На заставке появляется «Обновить»; бой в другой вкладке этой же сборки блокирует её обновление. Бой основной версии не мешает обновлять тестовую. Перед обновлением создаётся отдельная резервная копия; незавершённые бои проверяются на совместимость. Неполная загрузка сохраняет предыдущую рабочую сборку. Обновление самого общего загрузчика требует готовности всех вкладок. Первый вход в тест требует интернета, затем обе загруженные версии доступны офлайн.

Основная игра проверяет только `releases/stable.json`, тестовая — только `releases/test.json`. Основная не проверяет и не скачивает тестовую до переключения; выпуск нового теста не меняет основную сборку и общий Service Worker. Адаптер переключения и уведомлений входит в общий загрузчик, отдельно от игрового пакета. Для перехода со старого загрузчика достаточно одного его обновления: номер актуальной игры при этом остаётся прежним.

Браузер может удалить офлайн-данные при очистке хранилища или нехватке места. Для долгосрочного хранения прогресса используйте экспорт профиля.

## Разработка

- `src/game.js` — игровая логика и отрисовка;
- `src/battle.js` — рост отрядов, способности командиров, ремонт и прогноз входов; сборщик включает его перед инициализацией игры;
- `src/style.css`, `src/index.html` — интерфейс;
- `art/` — графика, без изменения исходных PNG;
- `src/pwa.js`, `src/sw.template.js` — автономный одиночный PWA-пакет;
- `hosting/` — общий загрузчик, разделение сохранений и Service Worker двух каналов;
- `version.json` — номер сборки и версии форматов сохранений;
- `scripts/build.py` — сборка без внешних зависимостей;
- `scripts/build_site.py` — объединение закреплённой основной и тестовой сборок;
- `deployment.json` — закреплённый коммит основной версии и рабочая ветка теста;
- `.github/workflows/pages.yml` — проверка и публикация GitHub Pages.

Сборка: `python scripts/build.py`.

Проверка: `python -m unittest discover -s tests -v`.

Локальный предпросмотр в одном HTML внутри ZIP: `python scripts/offline.py kontur_preview.zip` после сборки. Распакованный HTML открывается без сервера и интернета; PWA-обновлятор в нём отключён. Онлайн- и локальная версия хранят профиль в разных браузерных источниках: для переноса используется экспорт/импорт профиля.

Локальный запуск после сборки: `python -m http.server 8080 --directory dist`. Адрес `http://localhost:8080/` поддерживает Service Worker для разработки.

Общий сайт: `python scripts/build_site.py --stable <основные-исходники> --test <тестовые-исходники>`, результат в `site/`. Для проверки нужен HTTP-сервер с этой папкой как корнем. Исходники основной версии должны соответствовать `stableRef` и `stableVersion` из `deployment.json`.

Все изменения игры сначала готовятся в ветке `test`. Формат номера — `major.build.testBuild`: например, поля `1`, `30`, `1` дают **1.030.01**, следующий тестовый выпуск — **1.030.02**. При переносе в основную версию сохраняется полный проверенный номер, включая последний компонент. Сборщик не обрезает его для основной версии.

Публикация выполняется ручным запуском workflow `Publish Kontur channels`. Обычный push сам сайт не публикует. Workflow берёт конфигурацию из `main`, закреплённый коммит основной версии и ветку `test`; обе сборки выкладываются одним артефактом. Смена теста не меняет закреплённую основную сборку. Хеши ресурсов позволяют повторно использовать неизменённую графику.

Публикация теста и перенос в основную версию выполняются только по отдельным явным командам владельца. Перенос требует обновить исходники `main` и явно изменить `stableRef`/`stableVersion` на проверенный тестовый выпуск. До команды изменения и проверки остаются локальными.

При изменении структуры боя обновляйте миграции сохранений и `runFormats` в `version.json`. Форматы профиля и ключи локального хранилища нельзя менять без миграции.
