# КОНТУР

Sci-fi Tower Defence: кампания из 29 секторов на четырёх планетах и отдельная бесконечная оборона.

Играть: **https://runner2k11.github.io/kontur/**

## PWA и сохранения

После полной первой загрузки игра доступна офлайн в том же браузере. Её можно установить через меню браузера. Сектора, звёзды, технологии и незавершённые бои хранятся локально; автоматической синхронизации между устройствами нет.

Для переноса прогресса из прежнего HTML экспортируйте профиль через меню старой игры, затем импортируйте его в меню веб-версии. Экспорт профиля переносит сектора, звёзды и технологии; активный бой в этот файл не входит.

Новая версия скачивается в фоне. На заставке появляется кнопка «Обновить». Пока в любой открытой вкладке идёт бой, переключение версии блокируется. Перед переключением создаётся локальная резервная копия сохранений `kontur_update_backup_v1`. Форматы незавершённых боёв проверяются на совместимость. Старые рабочие файлы остаются в кэше, если новая версия не загрузилась полностью.

Браузер может удалить офлайн-данные при очистке хранилища или нехватке места. Для долгосрочного хранения прогресса используйте экспорт профиля.

## Разработка

- `src/game.js` — игровая логика и отрисовка;
- `src/style.css`, `src/index.html` — интерфейс;
- `art/` — графика, без изменения исходных PNG;
- `src/pwa.js`, `src/sw.template.js` — офлайн-доступ и обновления;
- `version.json` — номер сборки и версии форматов сохранений;
- `scripts/build.py` — сборка без внешних зависимостей;
- `.github/workflows/pages.yml` — проверка и публикация GitHub Pages.

Сборка: `python scripts/build.py`.

Проверка: `python -m unittest discover -s tests -v`.

Локальный запуск после сборки: `python -m http.server 8080 --directory dist`. Адрес `http://localhost:8080/` поддерживает Service Worker для разработки.

При выпуске увеличьте `build` в `version.json`. Публикация изменений в `main` запускает сборку, проверки и GitHub Pages. Хеши в именах файлов меняются только при изменении содержимого; прежняя графика повторно используется из кэша.

При изменении структуры боя обновляйте миграции сохранений и `runFormats` в `version.json`. Форматы профиля и ключи локального хранилища нельзя менять без миграции.
